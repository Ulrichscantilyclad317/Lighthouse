## 🛠️ Troubleshooting

### Common Issues and Solutions

**Application won't launch**
- Ensure your system meets minimum requirements
- Verify that your graphics drivers are up to date
- Check that all necessary runtime libraries are installed (DirectX, Visual C++ Redistributable)

**ROM not recognized**
- Verify the SHA-1 checksum of your ROM file
- Ensure the ROM is in the correct format (.z64)
- Try renaming the file to match the supported format

**Graphics issues**
- Update your graphics drivers
- Try different rendering backends (OpenGL, Vulkan, DirectX)
- Reduce graphics settings if experiencing lag

**Audio problems**
- Check your audio device settings
- Try different audio backends
- Ensure your system audio is working properly
